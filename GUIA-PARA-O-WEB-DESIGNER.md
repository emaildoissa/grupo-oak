# Grupo Oak — guia de implementação

## Direção visual

- Preto principal: `#090909`
- Dourado: `#D8AE58`
- Vermelho de apoio: `#C9232C`
- Fundo claro: `#F3F0E9`
- Tipografia sugerida: Manrope para títulos e DM Sans para textos

## Estrutura da página

1. Abertura institucional
2. Sobre o Grupo Oak
3. Portfólio das cinco marcas
4. Modelo operacional
5. Indicadores de força operacional
6. Área de parcerias e expansão
7. Chamada de contato
8. Rodapé institucional

## Materiais

- `assets/`: imagens otimizadas para uso direto na página.
- `downloads/`: fotografias originais em PNG e alta resolução.
- `index.html`, `styles.css` e `site.js`: página funcional e responsiva na raiz do projeto.

## Antes da publicação oficial

- Substituir os links dos botões finais pelo WhatsApp ou e-mail institucional do Grupo Oak.
- Confirmar os indicadores operacionais publicados.
- Se houver versões vetoriais dos logotipos, substituir os JPEGs mantendo os mesmos nomes ou atualizando as referências no HTML.
